# Changelog

All notable changes to AgriSmart AI are documented in this file.

The format follows the spirit of [Keep a Changelog](https://keepachangelog.com/)
and version numbers follow semantic-versioning conventions where practical.

## [1.0.0] - 2026-07-27

### Added

- Flask application, crop prediction API, health endpoint, history, dashboard, and
  model-information endpoints.
- Responsive frontend pages for landing, prediction, result, analytics, history,
  model information, About, and Contact.
- Frontend validation, loading states, toast notifications, theme controls, and
  accessible shared navigation.
- Prediction-service validation, persistence, logging, rate limiting, and tests.
- Docker, Docker Compose, Gunicorn, production logging, and deployment guidance.
- Repository documentation, contribution guidance, security policy, and MIT license.

### Changed

- Improved accessibility, browser security headers, error handling, and dashboard
  resilience during quality assurance.

### Fixed

- Corrected dashboard health status reporting, navigation links, duplicate API
  logging, modal keyboard behavior, and input-boundary consistency.
